# ytm-alice remote — Windows

Десктоп-приложение для Windows: нативное окно (pywebview / Edge WebView2),
которое открывает веб-панель ytm-alice на Яндекс Станции.

Музыка по-прежнему звучит на колонке; приложение — пульт.

## Возможности

- экран первого запуска: адрес Станции с проверкой подключения (`/api/info`);
- автопоиск Станции в локальной сети (`alice.lan`, `alice.local` и перебор
  адресов подсети на порту `24721`);
- сохранение адреса в `%APPDATA%\ytm-alice-remote\config.json`;
- меню «Файл → Сменить адрес Станции» и «Выход»;
- загрузка `cookies.txt` через стандартный диалог выбора файла в панели;
- внешние ссылки (например, `google.com/device`) открываются в браузере по
  умолчанию;
- тёмная тема, иконка проекта.

## Требования

- Windows 10/11;
- WebView2 Runtime (обычно уже установлен вместе с Microsoft Edge);
- телефон/ПК и Станция в одной локальной сети;
- на Станции установлен и запущен ytm-alice.

## Установка (готовый exe)

Скачайте `ytm-alice-remote-windows.exe` из релиза:
https://github.com/gfkfkf/ytm-alice-remote-windows/releases/tag/v1.0.0

Запустите файл (SmartScreen может предупредить — «Подробнее → Выполнить
всё равно», так как exe не подписан сертификатом).

На первом экране введите адрес Станции (например, `192.168.1.50:24721`) или
нажмите «Найти Станцию в сети». После успешной проверки откроется панель.

## Сборка из исходников

Нужны Python 3.10+ и pip.

```powershell
pip install pywebview pyinstaller pillow
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Готовый exe появится в `dist/ytm-alice-remote.exe`. Скрипт сам
сгенерирует `icon.ico` из `icon.png`, если его нет.

Параметры: `.\build.ps1 -Name my-app`.

## Как это работает

Приложение — тонкая нативная оболочка (pywebview / Edge WebView2) вокруг
веб-панели ytm-alice:

- `ytm_alice_remote.py` — точка входа, окно, меню, API для JS (pywebview
  `js_api`);
- `SETUP_HTML` — встроенная страница настройки (тёмная тема, как в Android);
- `normalize()` / `check()` / `discover()` — разбор адреса, проверка
  `/api/info`, параллельный поиск по локальной сети;
- `config.json` — сохранённый адрес, читается при следующем запуске.

Cleartext HTTP разрешён настройкой WebView2 по умолчанию для локальной сети.

## Ограничения

- Само приложение не воспроизводит музыку: звук идёт с колонки.
- Панель доступна всем в локальной сети без пароля — так задумано в ytm-alice.
- Если панель открывается по собственному домену, добавьте его в настройках
  панели («Домены панели»), иначе сервер отклонит запрос (403).
- При отсутствии WebView2 Runtime приложение не запустится; установите
  [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).
